# Pocket Geology

> Your ignored photos compact into underground strata you can dig into.

A mobile photo vault that turns every unviewed picture into a sediment layer, with deeper layers becoming older, weirder, and more compressed. The weird twist is that excavating a fossil photo requires you to answer a one-word memory question, and wrong answers collapse the trench.

## Features
- Automatic photo stratification by date, location, and time since last view
- Tap-to-dig trench interface with depth meters and artifact reveals
- One-word memory quiz gates access to buried photos
- Weekly landslide report summarizes forgotten moments and suggests a memory ritual

## Stack
- Swift
- SwiftUI
- SQLite

## Getting started
```
Open PocketGeology.xcodeproj in Xcode, select an iOS Simulator, and run. Grant Photos and location permissions for full stratification.
```
